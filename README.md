# Jayesh Kadam — Neon Portfolio

A responsive single-page portfolio built with HTML, CSS and vanilla JavaScript. It uses the dark neon/cyberpunk visual direction from the reference design and details provided in the LinkedIn screenshots.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Push the contents of this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Other**; build command and output directory can remain empty/default for a static site.
4. Deploy.

## Before publishing
- Confirm the email address and all live project URLs.
- Replace the initials avatar with your own photo if desired.
- Verify internship dates and descriptions; the portfolio uses the information visible in the screenshots.
